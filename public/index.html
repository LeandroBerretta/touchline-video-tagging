USERS

Who can use Touchline

Admins tag, publish and manage. Viewers watch published videos. Everyone signs in with their own email.

The Users page needs a one-time setup. Run database/005_users.sql in the Supabase SQL Editor, then deploy the admin-users Edge Function in Supabase (Supabase dashboard › Edge Functions › Deploy a new function › Via editor, name it admin-users, paste supabase/functions/admin-users/index.ts, Deploy). Step by step: database/README.md. Then reload this page.

They get an email with a link to choose their password. Supabase's built-in email sends only a few emails an hour, so invite people a few at a time.

EDIT USER

Role
Password

You never see passwords. Send a reset link and they choose a new one.

Remove access

Deletes the account. They are signed out and can't sign in again unless invited. Videos, tags and playlists are not affected.

TEAMS

Teams and squads

Each video belongs to a team. When you tag, players are picked from that team's squad.

Teams need a one-time database update: run database/004_teams.sql in the Supabase SQL Editor, then reload this page.
